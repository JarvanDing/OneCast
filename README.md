# OneCast – 魔兽世界 Forever 一键钓鱼

**一键抛竿，同一键收竿。** OneCast 把钓鱼变成一个按键，并补上周边能力：按你的意愿使用诱饵、一本 WoW Forever 全部鱼类的图鉴、各区域钓鱼等级，以及统计你在水边的收获。

每次抛竿、收竿与上饵仍是你自己的按键。OneCast 从不会替你自动钓鱼。

## 快速上手
1. 安装后，在 **选项 → 按键绑定 → 插件 → OneCast**（或在 OneCast 自身选项中）绑定一个按键。
2. 站在水边按下即可抛竿。未装备鱼竿时，第一次按下会帮你装上，再按一次才抛竿。
3. 浮漂溅起水花时再按一次即可收竿。

更喜欢鼠标？**双击右键** 水面（需已装备鱼竿）可抛竿，右键点击浮漂可收竿。

## 功能

### 🎣 一键钓鱼
- 一键抛竿，同一键通过游戏的软交互收竿。
- 可选 **标记自己的浮漂**：抛竿后在浮漂上显示游戏的装备图标，方便区分别人的水花。
- 未装备鱼竿时，按键会装备背包中最好的鱼竿。
- 主副手武器会被记住，并在休息一段时间后（时长自定）、开战时，或一键换回。
- 收竿或开战时，按键立即恢复正常。
- 背包满时抛竿会警告；若自动拾取关闭，会提示开启。

### 🧰 工具箱
![工具箱窗口：选择诱饵、用施法键上饵，并对比有无诱饵时的每小时鱼数](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/tackle-box.png)

- 装备鱼竿时出现小按钮，显示诱饵、数量与剩余时间；即将耗尽时会闪烁。
- **由你选择诱饵**（按角色）：稀有诱饵只有你选中才会消耗；选定后不会自动换成别的。也可选 **能用的最好诱饵**。
- 左键上饵、使用「上饵」按键，或开启 **用施法键上饵**（先上饵，再按一次抛竿）。
- 对比 **有诱饵 / 无诱饵** 时的每小时鱼数。
- 在售卖你选定诱饵的商人处，持有少于 5 个时会聊天提醒。

### 📖 钓鱼图鉴
![图鉴：全部鱼类，已钓到的以彩色显示](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/collection.png)

![鱼类页面：渔获记录、出没区域与地图、配方](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/fish-page.png)

- 一本 **WoW Forever 全部鱼类** 的书：88 种渔获，涵盖普通鱼、特殊渔获、奖杯鱼与浮肿鱼，全账号共享，包括安装前已钓到的。
- 点击任意鱼类打开 **专属页面**：游戏描述、各角色渔获、首次钓获时间与地点、是 **白天还是夜间** 钓到的、所有出没区域及 **地图**，以及所用到的 **配方**。
- **按区域筛选、按名称搜索。** 选中当前区域并显示缺失项，即可看到这里还剩什么。
- 钓到角色从未见过的鱼时，聊天会提示这是 **图鉴新发现**。
- **记住鱼群点：** 装备鱼竿时悬停在鱼群上并抛竿，会把钓点标在图鉴的区域地图上。

### 🗺️ 下一片水域去哪
![区域页：按所需钓鱼技能列出全部区域，并对照你的技能](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/zones.png)

- **区域页：** 一眼查看各区域钓鱼等级、是否达标，以及该处已钓到多少种鱼。点击区域可查看其鱼类。
- **这片水域适合你吗？** 技能条显示钓鱼技能（含诱饵加成），以及此处是否会脱钩。
- 技能不足时，会提示背包中能补足差距的诱饵。
- 没有已知等级的区域，根据你自己的渔获与脱钩判断；脱钩也可标出标注等级偏低，连续 10 次无脱钩会清除该记录。

### 📊 会话统计
![统计窗口：钓鱼技能、区域判定、会话数据与渔获](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/stats.png)

- 抛竿时打开的统计窗口：渔获/抛竿次数、渔获率、钓鱼时间与 **每小时鱼数**。
- 分页显示 **本次会话**、当前 **区域**、**生涯** 总计，以及近期渔获 **日志**。
- **最佳钓点：** 同一区域内你钓过的每个湖、岸与河，按每小时鱼数对比。
- **技能提升：** 本会话已提升点数，以及大约还需多少次渔获升下一点或达到区域等级。
- 休息时聊天输出 **会话摘要**。
- 点击任意物品打开其 **WoW Forever Wowhead** 页面，便于复制。Shift-点击可在聊天中链接。

### 💰 渔获值多少
- 各分页显示全部渔获的商人价值。
- 配合 **Auctionator** 或 **TradeSkillMaster** 显示拍卖价值。打开拍卖行后可一键用 Auctionator 扫描全部渔获。

### ✨ 稀有渔获提醒
- 对绿色及以上品质（品质可自选）发出团队警告闪烁与音效。
- 在统计窗口右键任意鱼类标记为 **想要**，咬钩时提醒。

### 🏆 钓鱼大赛
- 荆棘谷周日大赛倒计时，进行中美味鱼计数，拿到 40 条时立即提醒。
- 开始前与开始时聊天提醒。

### 🔊 听清溅水声
- 抛竿期间提高音效音量。
- 可选地，装备鱼竿时压低或关闭音乐、环境音与对话。换回武器后恢复你自己的音量。

### ⚙️ 融入游戏界面
- 采用 WoW Forever 自身的 UI 风格，另有八套主题可选，从木板风的 **渔夫小屋** 到跟随角色的 **职业颜色**。
- 小地图按钮、插件隔间入口，以及拆成短页的选项：钓鱼、诱饵、声音、统计与提醒。
- 可拖动与缩放统计窗口，随时关闭。
- **更新内容** 页面展示每次更新。

## 打开方式
- **统计窗口：** 抛竿时打开，或右键小地图按钮。
- **工具箱：** 右键其按钮，或 `/onecast tackle`。Shift-拖动按钮可移动。
- **钓鱼图鉴：** 统计窗口中的图鉴按钮、Shift-点击小地图按钮，或 `/onecast book`。
- **选项：** 左键小地图按钮，或 `/onecast`。
- **按键绑定：** 施放/收竿、上饵、工具箱、钓鱼图鉴、换回武器，位于 选项 → 按键绑定 → 插件。

## 命令
| 命令 | 作用 |
|---|---|
| `/onecast` | 打开选项 |
| `/onecast stats` | 显示或隐藏统计窗口 |
| `/onecast tackle` | 工具箱设置 |
| `/onecast tackle reset` | 将工具箱按钮移回初始位置 |
| `/onecast book` | 钓鱼图鉴 |
| `/onecast theme` | 切换窗口主题（或 `/onecast theme dark`） |
| `/onecast reset` | 开始新会话 |
| `/onecast gear` | 换回武器 |
| `/onecast scan` | 用 Auctionator 估价渔获（需打开拍卖行） |
| `/onecast forgetpools` | 清除记住的鱼群点 |
| `/onecast new` | 更新内容 |
| `/onecast help` | 全部命令与选项 |

## 须知
- **专为 WoW Forever 制作。** 不支持经典旧世与正式服。
- 图鉴中的鱼类与配方已对照 WoW Forever 游戏数据核对。各鱼出没地点 Forever 尚未公布，因此区域来自经典版数据与玩家报告，并已标注。没有已知水域的鱼会用你自己的渔获补全。
- **区域钓鱼等级来自经典版数据**，Forever 可能不同；新区域尚无数据，因此也会统计真实脱钩以保持准确。
- 诱饵需主手装备鱼竿，上饵约需 5 秒。魔兽只允许插件在玩家按键时使用物品，因此装竿后诱饵不会自行挂上。
- 区域等级已支持各语言客户端；鱼群标记目前仍仅识别英文鱼群名。
- 鱼群会移动，标记表示曾经出现过的位置，而非当前位置。
- 拍卖价值需要安装 Auctionator 或 TradeSkillMaster。
