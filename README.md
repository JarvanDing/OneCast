# 哇，大鱼

**一键抛竿，同一键亦可收杆。** 本插件为 WoW Forever 钓鱼整理出键盘、鼠标或手柄上的一条完整流程，并围绕钓鱼提供浮漂光柱、诱饵与装扮、图鉴与统计、渔夫之路、营地制作等 1.0 功能。

每一次施放、收杆与上饵仍由你亲手按键完成，插件不会代你钓鱼。

> **中文 fork 说明：** 界面与文档面向中文玩家；可选在「选项 > 按键设置 > 插件 > 哇，大鱼」中额外绑定 **「收杆（与浮漂互动）」**，实现 **分键收杆**（施放键在线抛出时不会变成收杆）。

## 快速开始

1. 登录后若未绑定按键，会弹出小欢迎窗：点击按钮后按下你想要的施放键。（也可在 **选项 → 钓鱼** 顶部或 `/onecast setup` 随时修改。）
2. 站在水边按下施放键。若未装备鱼竿，第一次按键会先帮你拿竿，再按一次抛竿。
3. 浮漂起水花时再按一次收杆（若已绑定分键收杆，则用收杆键）。

**更习惯鼠标？** 装备鱼竿后，对水面 **双击右键** 抛竿，再对浮漂右键收杆。

**用手柄？** 装备鱼竿后，默认 **A / Cross** 施放与收杆；**两侧扳机 + 该键** 可先装竿；**Y / Triangle** 打开「哇，大鱼」窗口。均在 **选项 → 手柄** 中可改。

## 功能概览（1.0）

### 一键钓鱼

- 一个施放键完成抛竿；配合软交互或分键收杆完成提竿。
- 未拿鱼竿时自动装备背包中最好的鱼竿。
- 武器与装备会记住并在收工、进战斗或点「完成钓鱼」后换回。
- 进战斗或收线后按键立即恢复游戏默认行为。
- **钓鱼时自动拾取**、**快速拾取**（仅钓鱼相关战利品）。
- 背包满时抛竿会提醒。

### 手柄支持

- 装备鱼竿时专用 **钓鱼键** 施放/收杆，摘竿或进战斗即恢复。
- Forever **手柄界面**下，插件窗口纳入游戏自带导航（方向键移动、A 确认、B 关闭）。
- 手柄 **按键图标**（可调大小）与稀有渔获 **震动** 提醒。

### 会话统计

- 抛竿时打开统计窗口：**会话 / 钓点 / 全时段纪录** 三页；鱼时、金币时、脱钩、图鉴新鱼、技能进度等。
- **迷你条** 可代替完整统计条显示技能、区域、渔获率、诱饵与想要列表。
- 开箱树、技能提升飘字、想要列表、会话可持续至手动 **重置**。

### 工具箱、浮漂、图鉴与区域

- **工具箱：** 自选诱饵、施放键联动上饵、有/无饵鱼时对比。
- **标记浮漂：** 可选光柱与水面光环，多种颜色。
- **钓鱼图鉴：** 全账号渔获与宝藏、稀有度、地图、配方与搜索（`/onecast search`）。
- **区域阶梯** 与 **世界地图** 钓鱼条；**向商人出售钓鱼杂物** 一键或自动。

### 钓鱼装扮与渔夫之路

- **钓鱼装扮：** 各部位自动/自选/保持穿戴，换装预览，与鱼竿同步穿上或脱下。
- **装备指南：** 每根鱼竿与钓鱼装备的来源、加成与地图路径点。
- **渔夫之路：** 学徒→工匠四级进度、学习方式、需求与推荐钓点；专家书与纳特路径点。

### 营地、大赛与其它

- **营地** 页：鱼缸、鱼架、小屋与蓝图、篝火、优良/稀有钓鱼增益追踪。
- **荆棘谷钓鱼大赛** 倒计时与美味鱼计数、林格路径点。
- **调音量 / 降低动效 / 更大字号** 等无障碍与主题选项。
- **统一主窗口** 侧栏切换各页；`/onecast scale` 等调整大小与位置。

## 打开方式与命令

| 命令 | 作用 |
|---|---|
| `/onecast` | 打开选项 |
| `/onecast setup` | 选择施放键 |
| `/onecast stats` | 统计窗口（`session` / `spots` / `alltime` 指定标签） |
| `/onecast search <关键词>` | 搜索渔获、区域、配方、装备、等级与设置 |
| `/onecast book` | 钓鱼图鉴（`/onecast camp` 营地页） |
| `/onecast tackle` | 工具箱 |
| `/onecast wardrobe` | 钓鱼装扮 |
| `/onecast journey` | 渔夫之路 |
| `/onecast done` | 完成钓鱼：换回武器 |
| `/onecast reset` | 新开会话 |
| `/onecast riggle` | 林格·巴斯贝特路径点（大赛） |
| `/onecast pad` | 手柄状态诊断 |
| `/onecast help` | 命令与开关一览 |

按键绑定：**选项 → 按键设置 → 插件 → 哇，大鱼**（含 **施放**、可选 **收杆（分键收杆）**、工具箱、图鉴、装扮、渔夫之路等）。

## 须知

- 专为 **WoW Forever** 制作，不支持经典 ERA 与正式服零售版。
- 区域钓鱼等级等多来自经典数据，Forever 新区域会结合实钓脱钩统计校正。
- 拍卖价需 **Auctionator**、**TradeSkillMaster** 或 **Naowh Forever**。
- 用 `/onecast report` 可分享匿名钓获数据，帮助补全 Forever 数值。
