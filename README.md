# 哇，大鱼（OneCast）– 魔兽世界 Forever 一键钓鱼

**一键抛竿收竿，也可分键。** OneCast 把钓鱼变成一个按键（或抛/收两个键），并补上周边能力：按你的意愿使用诱饵、一本 WoW Forever 全部鱼类的图鉴、各区域钓鱼等级，以及统计你在水边的收获。

每次抛竿、收竿与上饵仍是你自己的按键。OneCast 从不会替你自动钓鱼。

## 快速上手
1. 安装后，在 **选项 → 按键绑定 → 插件 → OneCast**（或在 OneCast 自身选项中）绑定「施放」。可选再绑「收杆」：绑了之后，施放键只会抛竿，不会再变成收杆。
2. 站在水边按下施放即可抛竿。未装备鱼竿时，第一次按下会帮你装上，再按一次才抛竿。
3. 浮漂溅起水花时：一键模式再按施放收竿；分键模式按「收杆」。

更喜欢鼠标？**双击右键** 水面（需已装备鱼竿）可抛竿，右键点击浮漂可收竿。

## 功能

### 🎣 钓鱼按键
- 默认一键：抛竿后同一键通过游戏的软交互收竿。
- 可选分键：另绑「收杆」后，施放键始终只抛竿，收杆键只与浮漂互动。
- 可选 **标记自己的浮漂**：抛竿后在浮漂上显示游戏的装备图标，方便区分别人的水花。
- 未装备鱼竿时，施放键会装备背包中最好的鱼竿。
- 主副手武器会被记住，并在休息一段时间后（时长自定）、开战时，或一键换回。
- 收竿或开战时，一键模式下的临时覆盖会立即解除。
- 背包满时抛竿会警告；若自动拾取关闭，会提示开启。

### 🧰 工具箱
![工具箱窗口：选择诱饵、用施法键上饵，并对比有无诱饵时的每小时鱼数](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/tackle-box.png?v=0.8.0)

- 装备鱼竿时出现小按钮，显示诱饵、数量与剩余时间；即将耗尽时会闪烁。
- **由你选择诱饵**（按角色）：稀有诱饵只有你选中才会消耗；选定后不会自动换成别的。也可选 **能用的最好诱饵**。
- 左键上饵、使用「上饵」按键，或开启 **用施法键上饵**（先上饵，再按一次抛竿）。
- 对比 **有诱饵 / 无诱饵** 时的每小时鱼数。
- 在售卖你选定诱饵的商人处，持有少于 5 个时会聊天提醒。

### 📖 钓鱼图鉴
![图鉴：全部鱼类，已钓到的以彩色显示](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/collection.png?v=0.8.0)

![鱼类页面：渔获记录、出没区域与地图、配方](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/fish-page.png?v=0.8.0)

- 一本 **WoW Forever 全部鱼类** 的书：91 种渔获，涵盖普通鱼、特殊渔获、奖杯鱼与浮肿鱼，全账号共享，包括安装前已钓到的。
- 点击任意鱼类打开 **专属页面**：游戏描述、各角色渔获、首次钓获时间与地点、是 **白天还是夜间** 钓到的、所有出没区域及 **地图**，以及所用到的 **配方**。
- **按区域筛选、按名称搜索。** 选中当前区域并显示缺失项，即可看到这里还剩什么。
- 钓到角色从未见过的鱼时，聊天会提示这是 **图鉴新发现**。
- **记住鱼群点：** 装备鱼竿时悬停在鱼群上并抛竿，会把钓点标在图鉴的区域地图上。

### 🗺️ 下一片水域去哪
![区域页：按所需钓鱼技能列出全部区域，并对照你的技能](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/zones.png?v=0.8.0)

- **区域页：** 一眼查看各区域钓鱼等级、是否达标，以及该处已钓到多少种鱼。点击区域可查看其鱼类。
- **这片水域适合你吗？** 技能条显示钓鱼技能（含诱饵加成），以及此处是否会脱钩。
- 技能不足时，会提示背包中能补足差距的诱饵。
- 没有已知等级的区域，根据你自己的渔获与脱钩判断；脱钩也可标出标注等级偏低，连续 10 次无脱钩会清除该记录。

### 📊 会话统计
![统计窗口的「会话」页：Forever 自带的钓鱼技能条、区域判定、每小时鱼数与金币，以及本次会话的渔获](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/stats.png?v=0.8.0)

抛竿时自动打开的统计窗口，分为三个标签页：
- **会话：** 本次会话的渔获、**每小时鱼数** 与 **每小时金币**。还有已提升的技能及速度、距离下一点和当前等级上限大约还需多久。渔获列表显示每种鱼的占比，之后是该区域你还没钓到的鱼。
- **钓点：** 这个区域值得钓吗？显示区域的每小时鱼数与金币，以及你在此钓过的每个湖、岸与河，最好的排在前面。点击某处可设置路径点。选中某种鱼（或在任意位置 Ctrl-点击）可查看它最爱在哪里咬钩、在此钓到它的频率，以及上次钓到的时间。
- **生涯纪录：** 个人最佳（每小时鱼数、每小时金币、单次会话的技能提升、最长会话）、值得一提的渔获（稀有物品、想要的鱼与图鉴新发现）以及生涯总计。
- 休息时聊天输出 **会话摘要**。
- 点击任意物品打开其 **WoW Forever Wowhead** 页面，便于复制。Shift-点击可在聊天中链接。

### 💰 渔获值多少
- 全部渔获的商人价值，以及每小时钓鱼的收益。
- 配合 **Auctionator** 或 **TradeSkillMaster** 显示拍卖价值。打开拍卖行后可一键用 Auctionator 扫描全部渔获。

### ✨ 稀有渔获提醒
- 对绿色及以上品质（品质可自选）发出团队警告闪烁与音效。
- 在统计窗口右键任意鱼类标记为 **想要**，咬钩时提醒。

### 🏕️ 营地钓鱼
![「营地」标签页：鱼缸、钓鱼架与钓鱼小屋，各自的需求与作用，以及你当前的营地](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/camp.png?v=0.8.0)

- 图鉴中的 **「营地」标签页** 介绍 Forever 的钓鱼制作：**鱼缸**、**钓鱼架** 与 **钓鱼小屋**，包括各自所需的钓鱼技能、你是否已学会、所需材料与作用。
- 统计窗口会显示钓鱼架或钓鱼小屋提供的 **优良或稀有钓鱼** 增益及剩余时间，增益消失时聊天会提示你。
- 营地增益生效期间钓到的渔获会被记录下来，用来看清它额外的奖励究竟是什么。

### 🏆 钓鱼大赛
- 荆棘谷周日大赛倒计时，进行中美味鱼计数，拿到 40 条时立即提醒。
- 开始前与开始时聊天提醒。

### 🔊 听清溅水声
- 抛竿期间提高音效音量。
- 可选地，装备鱼竿时压低或关闭音乐、环境音与对话。换回武器后恢复你自己的音量。

### ⚙️ 融入游戏界面
![「选项」标签页：「哇，大鱼」的全部设置，在窗口中分为两列](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/options.png?v=0.8.0)

- 采用 WoW Forever 自身的 UI 风格，另有十三套主题可选，从木板风的 **渔夫小屋** 和 **藏宝海湾**，到 **鱼人** 与跟随角色的 **职业颜色**。
- **一个窗口装下所有内容：** 统计、工具箱、图鉴、营地、数据报告、更新内容与选项，用侧边标签（可放在右侧或左侧）切换。所有页面等高，会在你上次拖动到的位置打开，`/reload` 后会回到你打开的那一页。
- **所有设置都在窗口里：** 「选项」标签页按游戏选项的顺序列出全部设置，滑块和选项就在那里。
- 小地图按钮与插件隔间入口。
- 缩放整个窗口（拖动任意页面的角、Ctrl + 鼠标滚轮，或 `/onecast scale`），或将其锁定在原位。
- 统计窗口在抛竿时打开、武器换回时关闭，钓鱼时还可以淡化。
- 有可分享的数据或可阅读的新版本时，侧边标签上会出现绿点。
- **更新内容** 页面展示每次更新。

## 打开方式
- **「哇，大鱼」窗口：** 左键小地图按钮打开列出所有页面的菜单，也可用侧边标签，或用「哇，大鱼」窗口的按键绑定（会打开你上次使用的页面）。
- **统计窗口：** 抛竿时打开，或右键小地图按钮。
- **工具箱：** 右键其按钮，或 `/onecast tackle`。Shift-拖动按钮可移动。
- **钓鱼图鉴：** 其侧边标签、统计页中的图鉴按钮、Shift-点击小地图按钮，或 `/onecast book`。
- **选项：** 窗口中的「选项」标签页有全部设置（`/onecast` 或小地图按钮的菜单可打开）。施法键在游戏选项中设置：`/onecast keys`。
- **按键绑定：** 施放、收杆（可选）、上饵、工具箱、钓鱼图鉴、换回武器与「哇，大鱼」窗口（会打开你上次使用的页面），位于 选项 → 按键绑定 → 插件。

## 命令
| 命令 | 作用 |
|---|---|
| `/onecast` | 打开选项 |
| `/onecast keys` | 打开游戏选项，设置你的施法键 |
| `/onecast stats` | 显示或隐藏统计窗口（`/onecast session`、`spots` 或 `alltime` 打开对应标签） |
| `/onecast tackle` | 工具箱设置 |
| `/onecast tackle reset` | 将工具箱按钮移回初始位置 |
| `/onecast book` | 钓鱼图鉴 |
| `/onecast camp` | 图鉴中的「营地」标签页 |
| `/onecast report` | 把你的钓鱼数据整理成文本，便于分享 |
| `/onecast theme` | 切换窗口主题（或 `/onecast theme dark`） |
| `/onecast reset` | 开始新会话 |
| `/onecast gear` | 换回武器 |
| `/onecast scan` | 用 Auctionator 估价渔获（需打开拍卖行） |
| `/onecast forgetpools` | 清除记住的鱼群点 |
| `/onecast new` | 更新内容 |
| `/onecast help` | 全部命令与选项 |

## 须知
- **专为 WoW Forever 制作。** 不支持经典旧世与正式服。
- 图鉴中的鱼类与配方已对照 WoW Forever 游戏数据核对。各鱼出没地点 Forever 尚未公布，因此区域来自经典版数据与玩家报告，并已标注。没有已知水域的鱼会用你自己的渔获补全。
- **区域钓鱼等级来自经典版数据**（包括副本和有独立等级的湖泊），Forever 可能不同；新区域尚无数据，因此也会统计真实脱钩以保持准确。
- 诱饵需主手装备鱼竿，上饵约需 5 秒。魔兽只允许插件在玩家按键时使用物品，因此装竿后诱饵不会自行挂上。
- 区域等级已支持各语言客户端；鱼群标记目前仍仅识别英文鱼群名。
- 鱼群会移动，标记表示曾经出现过的位置，而非当前位置。
- 拍卖价值需要安装 Auctionator 或 TradeSkillMaster。

## 帮忙补全 Forever 的数据
![数据报告：你的发现、分享的三个步骤，以及报告文本本身](https://raw.githubusercontent.com/rynmon/OneCast/main/assets/screenshots/report.png?v=0.8.0)

还没有人公布过 Forever 真实的区域钓鱼等级，也不知道较稀有的鱼在哪里能钓到。输入 `/onecast report`，点击 **选择报告**，按 Ctrl+C，然后粘贴到这里的评论中，或提交一份 [GitHub 上的数据报告](https://github.com/rynmon/OneCast/issues/new?template=data-report.yml)。报告窗口里已备好这两个链接，可直接复制。当你的钓鱼出现「哇，大鱼」还不了解的情况时，它会提示你，小地图按钮也会在你分享之前一直计数。报告会列出你的渔获和脱钩（含各自发生时的技能）、图鉴中缺少的鱼，不包含任何关于你身份的信息。有了足够的报告，「哇，大鱼」就能把经典版的数字换成 Forever 自己的数字。
